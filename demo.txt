6. Why forms.py is Used
forms.py is used to handle user input and validations.
Benefits:
Easy form creation
Built-in validation
Cleaner code
Secure form handling
Example:
from django import forms
from .models import Employee

class EmployeeForm(forms.ModelForm):

    class Meta:
        model = Employee
        fields = '__all__'


What is ModelForm?
ModelForm automatically creates a form using model fields.

What is class Meta?
Meta is an inner class used to configure the form.
It tells Django:
Which model to use
Which fields to include
Which fields to exclude
Custom widgets
Labels
Validations
model = Employee
model = Employee
This tells Django:
 “Create form fields using Employee model.”

fields = 'all'
fields = '__all__'
Meaning:
 Include ALL model fields in the form.

Specific Fields
fields = ['name', 'email']
Only these fields will appear:
name
email
city will NOT appear.
exclude
exclude is opposite of fields.
It removes specific fields from the form.
Example:
class Meta:
   model = Employee
   exclude = ['city']
Meaning:
Show all fields
EXCEPT city
Generated fields:
name
email
Not shown:
city

Difference Between fields and exclude
Option
Meaning
fields = 'all'
Include all fields
fields = ['name']
Include selected fields
exclude = ['city']
Exclude selected fields



Important Rule
 Do NOT use both together:
fields = '__all__'
exclude = ['city']
This will raise error.
Use ONLY one:
either fields
or exclude
Why forms.py is Useful
Benefits:
Automatic form generation
Validation support
Cleaner code
Easy database connection
Secure form handling

6. views.py
from django.shortcuts import render, redirect
from .forms import EmployeeForm
from .models import Employee


def add_employee(request):

   form = EmployeeForm()

   if request.method == 'POST':
       form = EmployeeForm(request.POST)

       if form.is_valid():
           form.save()
           return redirect('show_url')

   template_name = 'app1/AddEmployee.html'
   context = {'form': form}

   return render(request, template_name, context)


def show_employee(request):

   data = Employee.objects.all()

   template_name = 'app1/ShowEmployee.html'
   context = {'data': data}

   return render(request, template_name, context)


def update_employee(request, pk):

   obj = Employee.objects.get(id=pk)

   form = EmployeeForm(instance=obj)

   if request.method == 'POST':
       form = EmployeeForm(request.POST, instance=obj)

       if form.is_valid():
           form.save()
           return redirect('show_url')

   template_name = 'app1/AddEmployee.html'
   context = {'form': form}

   return render(request, template_name, context)


def delete_employee(request, pk):

   obj = Employee.objects.get(id=pk)
   obj.delete()

   return redirect('show_url')
